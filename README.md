# 八界具身智能开放社区

## 技术栈
- 后端：Nest.js + TypeORM + MySQL
- 前端：Vue3 + Vite + Tailwind CSS + Arco Design
- 部署：Docker Compose

## 快速开始
```bash
# 启动 MySQL
docker compose up -d mysql

# 后端
cd server && npm install && npm run start:dev

# 前端
cd client && npm install && npm run dev
```
